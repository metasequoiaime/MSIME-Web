# 水杉輸入法，讓中文輸入更順手

開源中文輸入法，支援全拼、雙拼與五筆。Windows、macOS 和 Linux 提供下載，iOS 版仍在開發中；各平台的功能與發布進度有所不同。

## 按照習慣設定輸入方式

使用全拼、雙拼或五筆輸入，搭配輔助碼縮小同音候選範圍。Windows 版可調整候選字視窗的字型、字級、排列方式與佈景主題，也提供自訂詞庫、語音輸入等工具。

[查看功能與介面](/zh-TW/features/)

## 選擇你的平台

- **Windows 10 / 11**：公開測試，提供安裝程式。
- **macOS 12 以上**：提供測試版本與安裝套件。
- **Linux**：提供測試版本，適用於使用 IBus 的桌面環境。
- **iOS**：仍在開發中，尚未提供公開下載。

[前往下載](/zh-TW/download/)

## 本機處理與連線功能

拼音轉換、詞庫查詢與詞頻學習在本機進行。Windows 和 Linux 預設開啟雲端候選字，可在設定中關閉；AI 聯想、線上翻譯與語音功能依平台和設定而異。

目前公開下載的輸入法可免費使用。若使用第三方服務，可能需要自行申請 API 憑證並支付服務費用。[隱私說明（簡體中文）](/privacy/)與[價格說明（簡體中文）](/price/)提供詳細資訊。

## 繁體中文網站與輸入功能

本版網站採用臺灣繁體中文用語。網站語言不會變更輸入法的輸出模式，也不代表各平台已具備完整的臺灣或香港詞庫。可用輸入方案與繁簡轉換方式，請以安裝版本和使用指南為準。

遇到問題可先查看[常見問題](/zh-TW/faq/)，也歡迎[回報問題或提出建議](/zh-TW/feedback/)。使用指南目前為簡體中文。
