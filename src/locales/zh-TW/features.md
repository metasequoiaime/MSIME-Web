# Windows 版功能與介面

本頁以 Windows 版為例介紹主要功能。其他平台的功能與操作方式，請查看對應版本的使用指南。

## 候選字視窗

候選字可採用橫排或直排，並調整字級與每頁顯示數量。不同應用程式的相容情況可能有所差異，遇到顯示問題時，可先在記事本中比較。

![瀏覽器中的水杉輸入法候選字視窗](/img/edge-screenshot-840w.webp)

## 全拼、雙拼與五筆

全拼適合直接輸入完整拼音；熟悉雙拼的使用者可選擇小鶴、自然碼、首道或微軟方案。五筆提供 86 版。方案的實際選項以所安裝版本為準。

## 輔助碼

在拼音後補上一至兩碼，可以縮小同音候選範圍、減少翻頁。可選方案包括藍天小雨點、自然碼、首右 2.0、首右 Plus 與小鶴。

![Windows Terminal 中顯示輔助碼的候選字視窗](/img/wt-screenshot-840w.webp)

## 設定與佈景主題

可調整字型、字級、排列方向、快捷鍵與配色。內建 Fluent、微信綠、石墨 Graphite 與楊柳青 Willow green 佈景主題，也可依照[佈景主題範例（簡體中文）](https://github.com/metasequoiaime/metasequoia-ime-skin-example)加入自訂主題。

![水杉輸入法深色設定介面，應用程式截圖為簡體中文](/screenshots/settings-dark-840w.webp)

## 詞庫與輸入工具

Windows 版提供詞庫查詢、詞條新增與權重調整，也包含懸浮工具列、螢幕小鍵盤、手寫辨識與語音輸入工具。詞庫匯入格式和工具操作請依使用指南設定。

雲端候選字、AI 聯想、線上翻譯與雲端語音辨識會使用網路，部分功能需自行設定服務憑證。[查看隱私說明（簡體中文）](/privacy/)。
