# 回報問題或提出建議

你可以使用繁體中文描述問題，不需要自行翻成簡體中文。網站會透過既有回報表單，在 GitHub 對應專案建立公開的 Issue（回報紀錄），無需 GitHub 帳號。

## 回報前準備

1. 選擇使用的平台；網站或文件問題也可單獨選擇。
2. 用一句話說明問題，附上輸入法與作業系統版本。
3. 描述操作步驟、預期結果與實際結果；相容性問題請補上應用程式名稱。
4. 如需截圖，先遮住個人資料與服務憑證。支援 PNG、JPEG、WebP，最多 3 張，每張不超過 5 MiB。

可先搜尋[常見問題](/zh-TW/faq/)，避免重複回報。新功能建議請說明使用情境及希望改善的地方。

## 開啟回報表單

表單介面與各專案的 Issue 範本目前為簡體中文，可以直接填入繁體中文。送出前可切換至「预览」檢查內容。

[填寫回報表單（簡體中文）](/feedback/)

## 公開範圍與後續處理

文字、截圖和自願填寫的聯絡方式會公開刊登於 GitHub；聯絡方式可以留空。請勿提供密碼、API 憑證或不願公開的輸入紀錄。

提交成功後會顯示 Issue 連結。維護者會在對應專案討論與評估，提交不代表已排入開發時程。若不確定是否提交成功，請先查看最新 Issue，確認後再重試。

安全漏洞或涉及隱私的問題，請依[安全政策（簡體中文）](https://github.com/metasequoiaime/.github/blob/main/SECURITY.md)私下回報，不要使用公開表單。
