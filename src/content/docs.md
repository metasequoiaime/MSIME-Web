# 水杉输入法文档

水杉输入法（Metasequoia IME）是一个面向 Windows 的开源自由的中文输入法项目，目标是改善 Windows 下的中英文输入体验。

## 项目简介

水杉输入法采用纯 TSF 方案，项目代码保持开放，方便用户了解输入法的组成和运行方式。

当前文档会逐步补充安装、配置、输入方案和常见问题。你也可以通过页面右上角的“开源代码”进入各个子项目。

## 下载安装

请前往 [GitHub Releases](https://github.com/metasequoiaime/MetasequoiaImeTsf/releases) 下载最新版本。

下载后请根据发布说明完成安装。不同版本的安装方式和功能可能会变化，以对应版本的发布说明为准。

![安装完成截图](/screenshots/install-finish.png)

这里请默认完成并启动 Metasequoia IME Server 和 Metasequoia IME Watchdog。

安装完成后，请使用 Win + Space 快捷键切换到水杉输入法，即可使用水杉输入法输入文字。

## 项目结构

- [MetasequoiaImeTsf](https://github.com/metasequoiaime/MetasequoiaImeTsf): 核心 TSF。
- [MetasequoiaImeServer](https://github.com/metasequoiaime/MetasequoiaImeServer): Server 端，负责算法和窗口渲染。
- [MetasequoiaImeUiHtml](https://github.com/metasequoiaime/MetasequoiaImeUiHtml): UI。
- [MetasequoiaImeDict](https://github.com/metasequoiaime/MetasequoiaImeDict): 词库。
- [MetasequoiaImeHelpCode](https://github.com/metasequoiaime/MetasequoiaImeHelpCode): 辅助码。

## 功能简介

- 支持全拼、双拼、五笔86。
- 拼音方案支持辅助码。
- 支持谷歌云联想。
- 支持 DeepSeek AI 联想。
- 支持词库管理、批量导入、导出。
- 支持手写识别。
- 支持快捷短语。

## 使用指南

### 辅助码

辅助码是一种可选的形码筛选功能。输入完整的拼音后，在末尾追加辅助码，可以缩小候选范围或调整候选顺序。

辅助码方案可以在配置中选择，目前支持：

- 蓝天小雨点
- 自然码
- 首右 2.0
- 首右 Plus
- 小鹤

辅助码有“单码”和“双码”两种使用方式，也可以分别用于全拼和双拼。

#### 单码辅助

在完整的拼音或双拼编码后追加一个辅助码。

单码辅助主要用于调整候选顺序：

- 单字：辅助码匹配汉字的任意一个形码。
- 词组：辅助码匹配词组首字或末字的首个形码。
- 匹配到的候选会被优先显示，但其他候选仍然保留。

例如，使用自然码辅助码时，“阿”的辅助码为 `ek`：

```text
全拼：aE
双拼：aae 或者 aaE
```

其中 E 表示追加的辅助码。实际输入时可以按住 Shift 输入大写字母。

注意：双拼追加的单码大小写都可以，但是全拼追加的单码必须是大写。

#### 双码辅助

在完整的拼音或双拼编码后追加两个辅助码。

**双码辅助**会严格筛选候选：

- 单字：两个辅助码分别匹配该字的两个形码。
- 词组：第一个辅助码匹配首字的首个形码，第二个辅助码匹配末字的首个形码。
- 筛选结果只保留符合辅助码的候选。

例如，“阿”的辅助码为 `ek`：

```text
全拼：aEK
双拼：aaeK
```

全拼输入时，两个辅助码使用大写字母；双拼输入时，通常使用“小写辅助码 + 大写辅助码”的形式，以便和单码辅助区分。

**全拼辅助**是在完整的全拼后追加辅助码：

```text
阿：aE       # 单码辅助
阿：aEK      # 双码辅助
阿姨：ayiE   # 单码辅助
阿姨：ayiEN  # 双码辅助
```

**双拼辅助**是在完整的双拼编码后追加辅助码。以小鹤双拼为例：

```text
阿：aae       # 单码辅助
阿：aaE       # 单码辅助
阿：aaeK      # 双码辅助
阿：aaEK      # 双码辅助
阿姨：aayie   # 单码辅助
阿姨：aayiE   # 单码辅助
阿姨：aayieN  # 双码辅助
阿姨：aayiEN  # 双码辅助
```

**注意**：辅助码只有在前面的全拼或双拼编码完整时才会生效。如果前面的拼音尚未完整，末尾输入的字母仍会按照普通拼音处理。

### 云联想

当前使用的谷歌的云联想 API，对网络有所要求。云联想如果返回了当前本地不存在的结果，会插入在首页的第二项。

### AI 联想

当前 AI 联想使用了 DeepSeek 的 API。AI 联想如果返回了本地以及 云联想都不存在的结果，会插入在首页的第三项。

### 候选项调频

可以在设置中自行选定调频算法。

### preedit 显示设置

用户可以通过设置->外观->行内预编辑和设置->外观->候选窗预编辑来控制应用内的拼音串和候选框内的拼音串的显示风格以及是否显示。

### 中英混输和英文输入法模式

开启中英混输模式，当预编辑拼音串大于 4 个字符时，会自动触发英文候选项。

在英文模式下，按下 Ctrl+Shift+E 快捷键可以 toggle 到英文输入法模式。

### 语音输入

语音输入需要在设置的“语音输入”分区启用，并填写 ASR API Token。当前默认使用硅基流动的语音识别服务，使用时需要网络连接。

#### 触发方式

默认启用以下两种快捷键：

| 快捷键     | 行为                                         |
| ---------- | -------------------------------------------- |
| 按住右 Alt | 开始录音，松开右 Alt 后停止录音并识别        |
| Ctrl + F9  | 切换录音状态，按一次开始，再按一次停止并识别 |

也可以打开输入法的右键菜单，点击“语音输入”来切换录音状态。点击一次开始录音，再点击一次停止录音并进行识别。

另外，配置中还支持以下快捷键，默认关闭：

- 按住 Ctrl + Win：开始录音，松开组合键后停止。
- 按住右 Ctrl + 右 Alt：开始录音，松开组合键后停止。

对于按住式快捷键，在录音过程中按下空格键可以锁定录音。锁定后松开右 Alt 或组合键不会停止录音，可以再次按下 `Ctrl + F9` 停止并开始识别。

录音过程中按下 `Esc` 会取消本次录音，并且不会提交识别结果。

组合快捷键需要按照先按修饰键、再按触发键的顺序使用，例如先按住 `Ctrl`，再按下 `Win` 或右 `Alt`。
