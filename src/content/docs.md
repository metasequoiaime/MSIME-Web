# 水杉输入法文档

水杉输入法（Metasequoia IME）是一个面向 Windows 的中文输入法项目，目标是改善 Windows 下的中英文输入体验。

## 项目简介

水杉输入法采用纯 TSF 方案，项目代码保持开放，方便用户了解输入法的组成和运行方式。

当前文档会逐步补充安装、配置、输入方案和常见问题。你也可以通过页面右上角的“开源代码”进入各个子项目。

## 下载安装

请前往 [GitHub Releases](https://github.com/metasequoiaime/MetasequoiaImeTsf/releases) 下载最新版本。

下载后请根据发布说明完成安装。不同版本的安装方式和功能可能会变化，以对应版本的发布说明为准。

## 项目组成

水杉输入法由多个相互协作的项目组成：

| 项目 | 说明 |
| --- | --- |
| [MetasequoiaImeTsf](https://github.com/metasequoiaime/MetasequoiaImeTsf) | Windows TSF 输入法端 |
| [MetasequoiaImeEngine](https://github.com/metasequoiaime/MetasequoiaImeEngine) | 输入法引擎 |
| [MetasequoiaImeDict](https://github.com/metasequoiaime/MetasequoiaImeDict) | 输入法词典 |
| [MetasequoiaImeCustomDict](https://github.com/metasequoiaime/MetasequoiaImeCustomDict) | 个人自定义词典 |
| [MetasequoiaImeHelpCode](https://github.com/metasequoiaime/MetasequoiaImeHelpCode) | 辅助码相关项目 |
| [MetasequoiaImeUiHtml](https://github.com/metasequoiaime/MetasequoiaImeUiHtml) | 输入法界面 |
| [MetasequoiaImeServer](https://github.com/metasequoiaime/MetasequoiaImeServer) | 服务端项目 |
