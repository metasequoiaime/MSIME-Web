# 关于水杉输入法

水杉输入法（Metasequoia IME）是一个开源中文输入法项目，支持全拼、双拼与五笔。Windows 版处于公开测试阶段，macOS 和 Linux 提供测试版本，iOS 版仍在开发中。欢迎下载体验，部分功能仍在完善中。

## 名字的由来

“水杉”这个名字来自开发者曾生活过的湖北省潜江市江汉油田。当地常见的水杉树，成为了项目名称的灵感。

## 项目理念

我们希望让输入和设置更方便，并通过公开源码与隐私说明，让用户了解输入法如何处理本地数据、哪些功能会联网。

各平台共用 C++ 输入引擎，界面与功能会随版本逐步完善。欢迎反馈问题，也欢迎参与代码、词库和文档的改进。

## 开源许可

Windows 版采用 [GPL-3.0 许可](https://github.com/metasequoiaime/MSIME-Windows?tab=GPL-3.0-1-ov-file)。其他组件及第三方依赖的许可，请以对应仓库的 LICENSE 和声明为准。
