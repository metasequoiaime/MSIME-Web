# 关于水杉输入法

水杉输入法（Metasequoia IME）是一个面向 Windows 的中文输入法项目，致力于改善 Windows 下的中英文输入体验。

## 项目理念

水杉输入法希望保持开箱即用、输入体验简洁、设置便捷、响应迅速，并通过开放项目代码，让用户能够了解输入法的组成与运行方式，以及，在一定程序上解决用户对隐私的焦虑。

项目目前仍在持续建设中，功能、界面和文档都会逐步完善。

## 开源许可

[GPL3.0](https://github.com/metasequoiaime/MetasequoiaImeTsf?tab=GPL-3.0-1-ov-file)

## 注意事项

水杉输入法安装程序有数字签名，以避免恶意篡改，减少杀毒软件误判。

- 可执行文件签署者为："Open Source Developer LU FAN"
- 数字签名机构为: Certum
- 下载水杉输入法安装包 exe 可执行文件后，如果 Windows 弹出程序没有签名的安全警告，可能是下载来源被篡改，请不要安装。

如果你发现内容有误，或有功能建议，欢迎提交 [Issue](https://github.com/metasequoiaime/MetasequoiaImeTsf/issues)。
