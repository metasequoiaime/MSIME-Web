# 关于水杉输入法

水杉输入法（Metasequoia IME）是一个开源的中文输入法项目，致力于改善桌面端的中英文输入体验。它从 Windows 上的纯 TSF 实现起步，现在各平台前端共用同一套 C++ 输入引擎：Windows 处于公开内测，macOS 与 Linux 已发布，iOS 前端正在开发中。

## 背景

水杉(MetaSequoia)这个名字取自于我这 GAP 两年多的地方，湖北省潜江市江汉油田，此地盛产水杉，我与此地结缘，遂以此树命名我一直以来想要开发的这款 Windows 输入法产品，希望这个产品能像水杉一样，给用户带来绿色的体验。

## 项目理念

水杉输入法希望保持开箱即用、输入体验简洁、设置便捷、响应迅速，并通过开放项目代码，让用户能够了解输入法的组成与运行方式，以及，在一定程度上解决用户对隐私的焦虑。

项目目前仍在持续建设中，功能、界面和文档都会逐步完善。

## 注意事项

Windows 版安装程序有数字签名，以避免恶意篡改，减少杀毒软件误判。

- 可执行文件签署者为："Open Source Developer LU FAN"
- 数字签名机构为: Certum
- 下载水杉输入法安装包 exe 可执行文件后，如果 Windows 弹出程序没有签名的安全警告，可能是下载来源被篡改，请不要安装。

如果你发现内容有误，或有功能建议，欢迎提交 [Issue](https://github.com/metasequoiaime/MSIME-Windows/issues)。
